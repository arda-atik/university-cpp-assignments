# 🎓 University C++ Assignments

This repository contains a collection of modular C++ programming assignments, system architecture exercises, and laboratory tasks completed during my Mathematical Engineering studies at the Czech Technical University in Prague (CTU / ČVUT).

## 🚀 Projects Overview

| Directory | Description | Key Concepts Demonstrated |
| :--- | :--- | :--- |
| [`lab01-ascii-table`](./lab01-ascii-table) | Generates a formatted ASCII character table with decimal and hexadecimal representations. | Console I/O, Type Casting, Loop Control, Stream Formatting |
| [`lab02-tui`](./lab02-tui) | Implements an interactive Terminal User Interface (TUI) menu system simulating file operations. | Modular Programming (`.h` / `.cpp`), Header Guards, Switch-Case Logic, CMake Build System |
| [`lab03-dot-product`](./lab03-dot-product) | Fixed-size arrays, standard I/O vector representation, and Euclidean dot product computation. | Array Processing, User Input/Output, Mathematical Operations |
| [`lab04-c-string-utilities`](./lab04-c-string-utilities) | Low-level C-style strings, custom `strlen`, ASCII character case conversion (`toUpper`), and integer parsing (`str2int`). | C-Style Strings, Null-Terminator Logic, Function Overloading, ASCII Manipulation |
| [`lab05-pointers-and-memory`](./lab05-pointers-and-memory) | Memory addressing, pointer dereferencing, and evaluation of call-by-value vs. call-by-pointer parameter passing. | Pointers (`*`, `&`), Memory Inspection, Parameter Passing Semantics |

## 🛠️ Tech Stack & Environment

* **Language:** C++ (C++20 Standard)
* **Build System:** CMake & Ninja
* **IDE:** JetBrains CLion
